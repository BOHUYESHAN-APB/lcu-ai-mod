OBS 地址

OBS 里加一个浏览器源就够：装备（四槽盔甲 + 耐久）、武器（主手/副手 + 耐久）、生命/饥饿/饱和度、当前任务都在这一页里，位置、缩放、透明度由本编辑器决定。宽度/高度按舞台填（如 1920×1080），`bg=transparent` 才是真透明底（后端跑在 127.0.0.1:8080 时，地址就是 http://127.0.0.1:8080/overlay?bg=transparent）。保存后 OBS 里的页面会在 ~5 秒内自己套用新布局（不必重加源）。
