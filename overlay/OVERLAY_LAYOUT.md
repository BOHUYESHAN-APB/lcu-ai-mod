# LCU 叠层 · 布局与配色清单

> 本文件只写**几何 / 颜色**，不写任何文案 —— 文案由用户在 OBS 里自己叠文字源（后期可改由 OBS 浏览器源从后端拉）。
> 画布 1920×1080，PNG 带 alpha。渲染后 alpha 会被 `overlay/render.py` **二值化**（>=128 → 255，<128 → 0），
> 所以叠层只有「开孔 alpha=0」和「实心 alpha=255」两种状态，不会在游戏画面上留下半透明脏边。

## 0. 渲染 / 自检

```bash
python overlay/render.py          # 重渲染两个 SVG → 二值化 alpha → 自检 → 出 preview_composite.png
python overlay/render.py --check  # 只对现有 PNG 自检（不重渲染）
```

渲染器：Chromium headless（本机没有 ImageMagick；PATH 里的 `convert` 是 Windows 的 FAT→NTFS 工具）。
透明底靠 `--default-background-color=00000000`，再用 Pillow 无损重压。

## 1. 图层顺序（OBS 自下而上）

1. `lcumod_overlay_base.png` —— 不透明整屏 UI（唯一透明处 = 用户 POV 内屏矩形）
2. AI 视角画面源
3. 用户 POV 画面源（在 AI 之上，交叠带靠它压住 AI）
4. `lcumod_overlay_top.png` —— 两台电视机外壳（透明）：**先画大框，再画小框** → 小框压住大框右下角

- 顶图 **POV 内屏 (1144,619) 720×405：alpha 严格 0**；

## 6. 遮挡 / 层次关系（由几何决定）

- 顶图里**先大框后小框、小框画满**：小框（不透明）把交叠区里大框的所有笔画盖掉 → 视觉上大框右下角是「断」的；小框自身的左上角边框会压在 AI 画面上（正常，顶图在视频源之上）。
- 底图的右侧蓝列 (下沿 546) 与底边蓝条 (右端 1088) 都已避开 POV 外壳 (1100, 575)，不再被压。
- 大电视外壳上沿 y=40 压住品牌条下沿 16px → 品牌条内容请放在 y ≤ 34 一条内。
- 交叠带 (1144,619)-(1360,814) 内，POV 画面源必须叠在 AI 画面源之上（否则交叠效果反了）。
